# Contributing to Cosmonautics Parts

Thanks for taking the time to contribute to **Cosmonautics Parts**!

## Reporting Bugs
* Provide a clear and descriptive title.
* Describe the steps to reproduce the issue along with Minecraft, NeoForge, Create, Aeronautics, and Sable versions.
* Attach crash reports or `latest.log` files if available.

## Pull Requests
1. Fork the repository and create your branch from `main`.
2. Add or update unit tests where applicable.
3. Ensure `./gradlew test build` succeeds locally.
4. Follow existing Java naming and 4-space indentation conventions.
